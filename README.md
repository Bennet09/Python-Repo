# 🎯 Guess Number Game (Python)

A simple console-based Python game where the user tries to guess a randomly generated number between 0 and 10.

---

## 📌 Description

This project is a beginner-friendly Python application that demonstrates:

- User input handling
- Random number generation
- Conditional statements
- Basic game logic

The program generates a random number and asks the user to guess it. It then tells the user whether they guessed correctly or not.
